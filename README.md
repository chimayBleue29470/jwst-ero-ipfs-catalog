# 🔭 JWST ERO MIRI — IPFS Catalog

> The first decentralized catalog of James Webb Space Telescope Early Release Observations (ERO) FITS files, distributed over IPFS.

## Overview

This repository indexes the **15 official MIRI Level 3 science images** from the JWST Early Release Observations (July 2022), pinned on IPFS for permanent, decentralized access.

All files are the official HLSP products from [MAST/STScI](https://archive.stsci.edu/hlsp/jwst-ero), licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

## How to access the data

### Via a public IPFS gateway
```
https://ipfs.io/ipfs/<CID>
https://cloudflare-ipfs.com/ipfs/<CID>
https://dweb.link/ipfs/<CID>
```

### Via your local IPFS node
```bash
ipfs get <CID> -o output.fits
```

### Pin the entire collection (one command)
```bash
ipfs pin add QmTU1hFS3487M9PsKNGy2LNSnDLpSDUZV2DnHepW55JDcN
```

## About FITS files

FITS (Flexible Image Transport System) is the standard format for astronomical data. To open these files:

- **Python**: [`astropy`](https://www.astropy.org/) — `fits.open('file.fits')`
- **Desktop**: [DS9](https://sites.google.com/cfa.harvard.edu/saoimageds9) or [CARTA](https://cartavis.org/)
- **Online**: [AstroImaging Channel Viewer](https://nova.astrometry.net/)
